# Security Policy

[简体中文](SECURITY.md) | [English](SECURITY.en.md)

## Reporting a security issue

Do not post accounts, cookies, platform sessions, raw response evidence, or customer data in public issues. Report vulnerabilities through the repository's private security-reporting channel.

## Security principles

- Do not bypass authentication, CAPTCHAs, rate limits, WAFs, or platform rules.
- Do not store credentials in source code, logs, manifests, or screenshot filenames.
- Monitoring output stays local unless the data owner explicitly authorizes an upload.
- External source content is evidence for verification and must not be copied into publishable content.

This project is currently Alpha software. Any use involving compliance, brand facts, or automated publishing requires human review.
